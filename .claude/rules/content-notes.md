# コンテンツ・デザイン担当メモ

## サイトの目的
**hoshiorange の公式ハブサイト**。各 SNS / 活動拠点へのリンクを集約し、SNSから流入した人が他の活動にも回遊できる「中継地点」として機能させる。

- 想定読者: 各 SNS（X / YouTube 等）から「hoshiorange って何者？」と興味を持って訪れた人
- 役割:
  1. 各種 SNS アカウント・チャンネル・ブログ等への導線
  2. プロフィール／自己紹介
  3. お仕事募集・連絡先
  4. 将来作る HP・ブログ・note 等を載せる場所

似た系統: Linktree / Pop / lit.link を、自分のドメインで・自分の見た目で持つイメージ。

## 表示名
- **ほし**（サイト上の名乗り）
- 英表記の hoshiorange はサブ／URL／OGP 等で使用

### 課題1: 床(floor)と壁(wall)が似て区別しにくい

**現状の色（3ファイルに同値で重複ハードコード）**
- 氷 ice `#7fb8e6`（明るい水色）／ 壁 wall `#2a3358`（暗い紺）／ 床 floor `#49507a`（くすんだ青紫）
- 定義場所:
  1. `src/games/koori-no-nukemichi/assets/manifest.ts` … `ice/wall/floor.color`（0x 数値, Pixi プレイヤー描画）
  2. `src/games/koori-no-nukemichi/editor/EditorGrid.tsx` … `TILE_COLOR` 定数（エディタのグリッドセル背景）
  3. `src/games/koori-no-nukemichi/editor/StageEditor.tsx` … `SWATCH` 定数（パレットボタンのスウォッチ）
  - 加えて `player/BoardRenderer.ts` に装飾ストローク: 床枠 `0x8a92c8` / 壁枠 `0x475089`
- **問題**: 壁 `#2a3358` と床 `#49507a` は色相がほぼ同じ青紫（hue ≈ 225°）で、明度差も小さく隣接コントラスト ≈ 1.5:1 と低い。夜空背景(#060814)上で両方が暗くまとまり「同じ青紫の濃淡」に見える。氷(明るい水色)は十分区別できているので、問題は wall↔floor 限定。

**改善方針**: 「氷=明 / 床=中 / 壁=暗」の明度3段に加え、床に色相を振って壁と決別させる。色相だけに頼らず明度差を必ず付け、色覚多様性（赤緑型）でも判別できるようにする。

**案2（オールクール＋ティール床 / 推し）** — 夜空テーマ親和・オレンジ非干渉
- 氷 ice `#86d2f2`（明るい水色・やや鮮やか / 高明度・寒色）
- 床 floor `#2f8f7d`（くすんだ緑青ティール / 中明度・緑寄り）
- 壁 wall `#1b2138`（暗い紺・ほぼ無彩 / 低明度）
- ねらい: 氷(青)/床(緑青)/壁(暗紺)を色相＋明度で二重分離。ティールはオーロラ・氷の洞窟感で夜空テーマと馴染み、マスコット/ゴールのオレンジ系とも干渉しない。装飾ストローク: 床枠 `0x5fc2ad` / 壁枠 `0x39406a`。

**案1（寒暖コントラスト床 / 代替）** — 一目の識別性を最優先
- 氷 ice `#86d2f2`（同上）
- 床 floor `#c2a06a`（くすんだ砂金・暖色 / 中明度）
- 壁 wall `#1b2138`（同上・暗紺）
- ねらい: 床を暖色にして寒色の氷と寒暖で最大コントラスト。青-黄軸は色覚タイプを問わず保たれやすく識別性◎。ただし氷世界に砂色はやや浮く＋ゴール淡黄(#ffd27f)と色相が近い（床は彩度を抑えて回避）。装飾ストローク: 床枠 `0xe0c79a` / 壁枠 `0x39406a`。

両案共通: 壁を現状より暗くして「通れない＝沈む」を強調、氷をやや鮮やかにして「滑る」を強調。
- ダーク/ライト: ゲーム画面・エディタとも背景は夜固定（#060814）なので、サイトのライトテーマでの破綻懸念は実質なし。
- **適用箇所 対応表（実装担当向け / 3ファイル＋装飾を同値で更新）**

| 論理タイル | manifest.ts（0x） | EditorGrid `TILE_COLOR` | StageEditor `SWATCH` | BoardRenderer ストローク |
|---|---|---|---|---|
| 氷 ice | `ice.color` → 0x86d2f2 | `[Tile.Ice]` → '#86d2f2' | `ice` → '#86d2f2' | 白ハイライト（維持） |
| 壁 wall | `wall.color` → 0x1b2138 | `[Tile.Wall]` → '#1b2138' | `wall` → '#1b2138' | wall枠 0x475089 → 0x39406a |
| 床 floor | `floor.color` → 案2:0x2f8f7d / 案1:0xc2a06a | `[Tile.Floor]` → 同値 | `floor` → 同値 | 床枠 0x8a92c8 → 案2:0x5fc2ad / 案1:0xe0c79a |

- 注（実装向け補足）: 色が3ファイルに重複している。今回は3箇所＋装飾を同値更新。将来は manifest を単一の出典にして EditorGrid/StageEditor が参照する形にすると保守が楽（今回必須ではない）。

### 課題2: アニメーション追加

前提: プレイヤーは既にスライドの ease-out 補間あり。`prefers-reduced-motion`（`useReducedMotion`）で動きを抑制する方針。各案に reduced-motion 時の退化を併記。実装は Pixi の ticker（プレイヤー）/ CSS transition（エディタ）。

**推し3つ（まずこれだけで効果的）**
1. クリア演出（ゴール到達時）｜コスト中｜テーマ◎ — マスコット到達でゴールの同心円がリング状に拡大フェード＋星きらめき＋マスコットが軽く跳ねる。達成感に直結。reduced-motion: アニメ無しで「クリア！」表示と色変化のみ。
2. マスコット待機フロート＋glow 呼吸｜コスト軽｜テーマ◎ — 静止中、ほのかに上下フロートし glow を明滅（呼吸）。「生きてる感」。reduced-motion: 停止（静止）。
3. 停止時バウンド/スカッシュ｜コスト軽〜中｜フィール◎ — 壁・縁・床で止まる瞬間、進行方向に軽くスカッシュして戻る（氷を滑って“こつん”）。スライドの気持ちよさ向上。reduced-motion: 即時停止のまま無し。

**その他メニュー**
4. スライド軌跡（トレイル）｜中｜テーマ◎ — 滑走中に薄い尾／通過セルがキラッ。氷感UP。reduced-motion: 無し。
5. 氷タイルのきらめき（shimmer）｜軽｜テーマ◎ — 氷ハイライトが周期/ランダムにキラッ。reduced-motion: 静止ハイライトのまま。
6. スタート登場演出｜中｜テーマ○ — 開始時にタイルが順にポップイン＋マスコットがふわっと登場。reduced-motion: 即表示。
7. ゴール常時アイドル（脈動）｜軽｜テーマ○ — ゴール同心円がゆっくり脈動して誘目。reduced-motion: 静止。
8. 入力予備動作｜軽｜フィール○ — キー/スワイプ入力時にマスコットが進行方向へ軽く沈む予備動作。reduced-motion: 無し。
9. エディタ配置フィードバック｜軽｜— — タイルを塗った瞬間セルが軽くポップ＋テストプレイのクリアバナーに軽い演出。reduced-motion: トランジション無し。

- 相性メモ: 星きらめき・glow 明滅・トレイルは StarryBackground（既存の星空アニメ）と統一感が出て夜空テーマと好相性。スカッシュ/バウンドはテーマより氷の物理フィール強化。
